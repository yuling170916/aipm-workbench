# AIPM工作台 UI 设计包

作者：yuling
版本：2026-10-09
状态：已确认的设计参考

## 查看方式

1. 解压 ZIP，保持文件夹结构不变。
2. 双击 `图片索引.html`，在浏览器里按页面名称查看。
3. 点击缩略图可打开高清 PNG；长页面可滚动或在图片查看器中放大。
4. 阅读 `首页与设置页-UI规范.md`，核对首页、设置页的布局与组件规则。

## 文件结构

- `01-主界面`：首页、助手、需求、模型对比、对话、定时任务、团队。
- `02-设置界面`：Agents、模型、技能、工具、外观、远程连接、桌面宠物、系统、归档、关于。
- `03-详情与弹窗`：助手与团队页签、消息渠道、需求体检/历史/文档、技能详情、登录，以及常用配置弹窗。
- `04-组件与总览`：按钮两态与图标间距规范图。
- `页面清单.md` / `页面清单.json`：每张图的编号、标题、页面入口与本地状态。
- `pages` / `assets`：静态 HTML 预览与品牌图片，可离线查看；按钮不连接实际功能。
- `图片校验.sha256`：页面 PNG 的校验清单。

本包共 50 张页面与组件 PNG。按 1440px 桌面窗口宽度、2 倍倍率导出，宽 2880px。普通长页面完整导出，弹窗和抽屉按当前窗口导出。示例项目、模型、任务与账号均用于展示布局。

设计沿用现有页面分区，采用蓝色为主的两态按钮、统一 16px 图标 / 22px 槽 / 8px 图文间距，品牌与桌面宠物使用同款蓝色毛绒 IP。源码已按本轮规范更新通用控件、导航与品牌 IP；本文件夹保留原始确认稿的示例数据和标注，PNG 不是本机实测界面截图。

图包覆盖固定页面及主要页签、详情与配置弹窗。悬浮提示、右键菜单、通用删除确认和动态插件专属设置不单独导图。页面入口中的 example 为示例标识；本地状态不是新增路由。
