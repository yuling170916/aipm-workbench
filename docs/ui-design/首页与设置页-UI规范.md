# AIPM工作台：首页与设置 UI 规范

版本：2026-10-09 · 作者：yuling · 状态：已确认的设计参考。

本文件记录用户已确认的视觉要求，作为设计与前端协作规格。源码已更新按钮两态、导航间距、首页控件布局与同款品牌 IP；运行界面读取真实配置与数据。附带 PNG 保留原始确认稿的示例内容和标注，不能作为功能执行结果。现有安装包需按构建说明重新构建以应用最新源码。

本文尺寸均为 CSS 逻辑 px。Retina、系统缩放、浏览器缩放与图片导出倍率都会改变截图像素；不能将截图中的像素数直接作为 CSS 尺寸。没有对应代码值的尺寸标为建议值，可在前端验收时按实际窗口微调。


## 0. 如何配合图片使用

解压设计包后，双击 `图片索引.html` 按页面名称浏览。`01-主界面` 包含首页等主页面；`02-设置界面` 包含固定设置项；`03-详情与弹窗` 包含页签、详情、登录和配置弹窗；`04-组件与总览` 包含按钮与间距规范。准确编号和文件名以 `页面清单.md` 为准。

图片按 1440px 桌面窗口宽度、2 倍倍率导出，PNG 宽 2880px；长页面保留完整内容。`pages` 文件夹内是可离线打开的静态 HTML 预览，用于核对布局，按钮不连接真实功能。

以本文的 CSS 逻辑尺寸为实现基准。图片中的项目、模型回答、任务与凭据均为示例，正式应用接入时读取真实数据。

## 1. 统一视觉基准

| 项目 | 设计目标值 | 使用位置 |
|---|---|---|
| 侧栏底色 | `#F3F7FE` | 首页与设置的同一侧栏 |
| 内容画布 | `#F7FBFF` | 主内容背景 |
| 默认控件底色 | `#FFFFFF` | 默认按钮、输入框、内容卡片 |
| 默认按钮边框 | `1px solid #DCE7FF` | 全部默认按钮 |
| 正文与默认按钮文字 | `#25334F` | 页面标题、正文、菜单文字 |
| 默认图标与辅助文字 | `#7E8CA6` | 线性图标、分组标题、说明 |
| 选中／主操作蓝色 | `#315FF4` | 选中导航、选中选项、主操作按钮 |
| 蓝色按钮文字与图标 | `#FFFFFF` | 所有实蓝按钮 |
| 图标 | 16px；22px 对齐槽 | 普通按钮与侧栏菜单 |
| 图标至文字的间距 | 8px | 首页、设置与其它页面的全部图文按钮 |
| 普通按钮高度 | 38px；侧栏 40px；标题栏图标按钮 36px | 侧栏导航、表单操作、筛选与工具操作 |
| 普通按钮圆角 | 12px | 默认与蓝色按钮一致 |
| 普通按钮字体 | 14px／500；行高 20–24px | 不随选中状态增粗 |
| 辅助文字字体 | 12px／400–500；行高 18–20px | 路径、说明、时间、空状态 |
| 页面标题字体 | 24–28px／600–700 | 设置页与工作区标题 |

普通图标采用同一套 outline 线性图标，不混用实心图标、emoji 或不同笔画风格。本包预览图使用 `24×24` SVG viewBox、`stroke-width: 1.6`、圆头与圆角连接；实际显示为 16px。当前源码使用 IconPark，迁移时保持同一视觉笔画粗细，避免直接混用两套图标。SVG 的 stroke 参数不等于最终屏幕像素线宽。默认图标为灰蓝色；实蓝按钮内的图标改为白色。

品牌 logo 和桌面宠物是品牌图片，保持自身颜色，不套用单色线性图标规则。纯图标按钮使用同一颜色与圆角规则；其内容居中，不需要人为补一段 8px 空白。

## 2. 两类按钮及状态

| 家族／状态 | 背景 | 边框 | 文字与图标 | 使用语义 |
|---|---|---|---|---|
| 默认 | `#FFFFFF` | `#DCE7FF`，1px | 深蓝文字、灰蓝图标 | 未选中导航、普通操作、未选中选项 |
| 选中／主操作 | `#315FF4` | `#315FF4`，1px | 白色 | 当前导航、当前选项、页面主操作 |
| hover | 沿用所属家族 | 在所属颜色内轻微加强 | 沿用所属家族 | 不改变选中语义 |
| pressed | 沿用所属家族 | 沿用所属家族 | 沿用所属家族 | 短暂反馈，松开后回到原状态 |
| focus-visible | 沿用所属家族 | 保留边框，外加蓝色焦点圈 | 沿用所属家族 | 键盘焦点，不等于选中 |
| disabled | 沿用原家族并降低可用感 | 保留形状 | 降低对比，保持可读 | 不可点击，不能仅靠颜色传达原因 |
| loading | 沿用原家族 | 保留形状 | 相同颜色的加载指示 | 防止重复执行，不改变按钮宽度 |

只建立上述两种视觉家族，不额外新增实灰、实紫或渐变按钮。警告、错误与需求状态标签仍保留已有语义；不可把不可点击的状态标签当作按钮处理。

导航、助手选项与页签具有持续选择态。保存、发送、刷新、导出等是执行操作：实蓝可表示主操作，但点击完成后不能产生虚假的持续“选中”状态。删除、停止等已有操作保留真实文案与行为，通过文案和现有确认流程表达语义，不新增未经要求的功能。

普通图文按钮采用 `inline-flex`、垂直居中、`gap: 8px`。图标占 22px 槽，实际图标 16px；左右内边距建议 12–16px。按钮文字不得因图标槽或长内容而挤压变形，过长标签使用省略与完整提示。

## 3. 首页布局

| 区域 | 尺寸与布局目标 | 层级与内容 |
|---|---|---|
| 全局侧栏 | 默认宽 260px；保留现有拖拽伸缩能力；内容左右留白 8–12px | 固定在左侧，首页与设置共用视觉规则 |
| 侧栏品牌区 | 高度至少 64px；品牌图片 36px；图片与名称间距 8px | 蓝毛绒 IP logo + “AIPM工作台” |
| 固定导航 | 每行 36–40px、12px 圆角、行距 4–6px | 原入口顺序不变；当前项实蓝白字 |
| 可滚动历史区 | 占剩余高度；与固定导航间留 12–16px 或细分隔线 | 保留现有置顶、团队、项目与会话顺序 |
| 首页主内容容器 | 最大宽 1040px，水平居中；左右内边距建议 32–42px | Hero → 输入区 → 快捷任务 → 最近项目 |
| Hero | 建议至少 200px 高，左右双栏；区域间距 16–24px | 左侧文案，右侧现有 IP 敲电脑图 |
| IP 主视觉 | 建议宽约 240–252px，高约 200px；等比 contain | 不遮挡主标题和输入区，不改变角色身份 |
| 输入卡片 | 横向撑满主内容容器；建议圆角 18px、内边距 18–20px | 输入正文、材料入口、模型与助手选择、发送按钮 |
| 快捷任务区 | 桌面 3 列，列间距 16px；窄屏转单列 | 整理需求／编写 PRD／检查遗漏 |
| 最近项目区 | 桌面 2 列、间距 14–16px；窄屏转单列 | 真实最近项目、工作目录、更新时间 |


### 1440px 桌面画布的定位基准

| 项目 | 本包预览的精确基准 |
|---|---|
| 顶部标题栏 | 高 48px，白底、底部 1px 浅蓝分隔线 |
| 左侧栏 | 宽 260px；左右 padding 12px；顶部 padding 22px |
| 导航按钮 | 宽 236px，高 40px；行间距 6px；左右 padding 10px |
| 菜单图标槽 | 宽高 22px；居中显示 16px 图标 |
| 菜单文字起点 | 相对窗口左边约 53px；所有导航行一致 |
| 主内容内边距 | 上 26px、左右 34px、下 38px |
| 主内容容器 | max-width 1040px；1440px 窗口下起点 x≈330px |
| 普通卡片 | padding 22px、圆角 18px、1px 浅蓝边框 |
| 普通按钮 | 高 38px、左右 padding 16px、圆角 12px |

```text
┌────────────────── 顶部标题栏 48px ───────────────────┐
│ 左侧栏 260px │              主内容                  │
│ 品牌 logo    │ 工作台 / 页面标题                     │
│ 固定导航     │ Hero：左侧文案 + 右侧敲电脑 IP         │
│ 团队 / 历史  │ 输入卡片：正文 → 助手、材料、模型、发送 │
│              │ 快捷任务：整理需求 / PRD / 检查遗漏    │
│ 底部设置     │ 最近项目：2 列卡片                    │
└──────────────┴──────────────────────────────────────┘
```

输入卡片正文区域至少 94px 高，底部操作与正文间距 12px；底部操作顺序为“产品经理 → 添加材料 → 默认模型 → 在项目中工作”，右侧为发送；选中的“产品经理”助手使用实蓝样式。快捷任务和项目卡片属于可点击内容卡，按内容展开，最小高度 84px，保留 12px 按钮圆角与 8px 图文间距。

### 首页侧栏

固定入口顺序：新建对话 → 首页 → 助手 → 需求工作区 → 模型对比台 → 定时任务。设计稿将当前源码里的“新会话”文案按用户要求展示为“新建对话”，对应功能仍是开始新对话。底部设置入口与其它既有入口保留实际位置。移动端现有搜索入口保留；桌面端现有标题栏搜索不额外重复放回侧栏。

各行共享同一图标槽、文字起点、按钮高度与圆角。不要把“新建对话”设计成与其它行高度、字重、图文间距不同的孤立按钮。当前页面的导航为实蓝白字；其它入口为白底浅蓝边框。其余菜单名称沿用现有文案，不把“首页”与“助手”合并成一个新入口。

### Hero 与输入区

保留首页文案层级：辅助标题“你的 AI 产品搭档”、主标题“让好想法，成为好产品。”、说明“从需求梳理到 PRD，把时间留给更重要的决策。”。主标题建议 32–36px／700，辅助标题 14px／500–600，说明 13–14px，行高 1.6–1.8。

输入提示保留“说说你的产品想法，或上传一份需求资料…”。输入框是白底浅蓝边框控件，不能因为与默认按钮相似而被当成按钮。底部材料、模型、模式与助手入口统一 8px 图文间距；选中的助手可使用实蓝白字，未选中使用默认家族。发送为实蓝主操作，未满足现有发送条件时保留不可用状态。

快捷任务保留现有卡片式布局与辅助说明。其点击行为仍为插入任务草稿并聚焦输入，不能在图稿中暗示自动发送或已完成生成。卡片中的可点击入口沿用两类家族，图文间距也统一 8px；卡片可按内容高度展开，不强行压成 36px 的单行按钮。

### 最近项目

标题为“继续最近的项目”，右侧“刷新项目”采用默认按钮家族。项目名称和更新时间必须来自实际数据，不在正式界面编造项目、数量或成绩。预览里的示例项目应标明示例。

加载状态显示读取提示；没有项目时显示现有空状态与“新建项目”；加载失败提供“重新加载”。这些状态沿用已有功能，排版对齐同一内容栅格。项目卡片的名称、路径与时间依次分层，不把路径当成主标题。

## 4. 设置布局与导航

设置页沿用与首页相同的左侧品牌区、260px 默认侧栏、图标槽和菜单行。内容区建议最大宽 1040px、左右内边距 32–40px；页标题与说明在同一左对齐线。表单和设置卡片建议最大宽 840–960px；具体面板按既有功能内容伸缩，避免为了统一视觉增加新的二级导航。

| 区域 | 建议规格 | 说明 |
|---|---|---|
| 设置分组标题 | 12px／500–600、灰蓝；上间距 16–24px | 比菜单文字更弱，不可点击 |
| 设置导航行 | 36–40px 高、12px 圆角、22px 图标槽、8px 图文间距 | 与首页固定导航一致 |
| 当前设置项 | 实蓝背景、白文字与白图标 | 不再采用旧浅蓝底深蓝字的选中态 |
| 内容页标题 | 24–28px／600–700 | 页面内最高层级 |
| 卡片／功能分区标题 | 16–18px／600 | 与说明文字有清楚层级 |
| 表单标签 | 14px／500 | 与控件起点对齐 |
| 表单控件 | 高度建议 36–40px、圆角 12px | 多行输入按内容展开 |
| 卡片间距 | 16–24px | 保持现有功能分区 |
| 操作行 | flex 对齐、按钮间距建议 8–12px | 主操作实蓝，普通操作白底边框 |

设置导航的实际分类和名称如下，顺序保持不变：

| 分类 | 菜单名称（顺序） |
|---|---|
| AI 核心 | Agents、模型、技能、工具 |
| 应用 | 外观、远程连接、桌面宠物、系统 |
| 已归档 | 已归档的对话 |
| 其他 | 关于 |

“Agents”为当前实际界面名称；本规范不擅自改成“助手”，以免与首页“助手”入口混淆。扩展新增的设置入口沿用既有插入规则，并继承同一视觉规格。远程连接与桌面宠物的既有显示条件保留。

桌面宠物入口的品牌展示使用现有蓝毛绒 IP；如果入口保留线性图标，应采用与同一角色一致的简化轮廓，不继续用猫形图标代表这只水獭。设置内容里的普通图标仍遵守 16px／22px 槽的统一规则。


### 设置页内容分区

设置内容沿“标题与说明 → 筛选或主操作 → 设置卡片 → 辅助说明”的顺序排列。右侧操作与所属设置行垂直居中，较长说明换行，不挤压开关或按钮。横向页签仍采用两态按钮，不使用第三种装饰样式。

| 设置项 | 页面内布局与内容顺序 |
|---|---|
| Agents | 标题与添加操作 → 搜索、全部/可用/不可用 → 安装提示 → Agent 列表 → 自定义 Agent；修复配置进入详情 |
| 模型 | 添加操作 → 模型平台卡片 → 平台状态与 API 信息 → 已配置模型；平台与模型设置弹窗延续同一按钮规范 |
| 技能 | 自定义/官方页签 → 搜索与导入 → 技能列表；技能详情与导入历史独立展示 |
| 工具 | MCP 操作与服务列表 → 图像生成配置；新增 MCP 延续通过对话添加、从 JSON 导入和一键导入入口 |
| 外观 | 明暗主题 → 字体（界面/对话/Markdown/代码）与缩放 → 自定义 CSS 主题；颜色统一但保留已有深色主题能力 |
| 远程连接 | WebUI/消息渠道页签；WebUI：服务开关 → 访问地址 → 账号配置；消息渠道：渠道列表与连接配置 |
| 桌面宠物 | 同款 IP 主视觉 → 启用开关 → 尺寸 → 免打扰 → 确认气泡；示例选择为中号 280px |
| 系统 | 基本偏好（含语言/启动/托盘/硬件加速）→ 会话与文件 → 通知 → 工作目录 → 语音输入 → 应用内浏览器；按实际内容垂直排列，页面可滚动 |
| 已归档的对话 | 标题 → 归档列表或空状态 → 恢复/删除等已有操作 |
| 关于 | 品牌信息 → 产品与署名（yuling）→ 参考与反馈；真实版本号由实现读取，许可证和第三方声明保留 |

本包图中的开启、关闭、未检测等状态用于演示布局；真实状态由应用读取。未配置模型时，图像生成等依赖模型的控件保留真实禁用原因。账号、密钥字段使用空值、占位符或掩码，不在设计图中显示真实凭据。

### 窄窗口与滚动

桌面基准是 1440px，页面缩小时保持现有侧栏伸缩和移动端导航能力。建议在内容宽度不足 760px 时，首页 Hero 改为上下排列，快捷任务与最近项目改为单列；设置行的操作可换到说明下方。普通按钮不压缩图标槽与 8px 间距，长文字可换行或按现有规则省略。长设置表单、需求卡和弹窗正文使用纵向滚动，底部操作保持可访问。

## 5. 桌面宠物与品牌形象

桌面宠物使用现有 logo 的蓝色毛茸茸水獭形象：蓝色绒毛、白色口鼻与腹部、深色圆眼、圆润短肢，保持亲和、有质感的表情。不得改成猫、树懒或另一个角色。“绒懒”按用户所指的 logo 形象理解，不按字面另创动物。

首页敲电脑图、侧栏头像、桌面宠物预览应保持同一脸型、配色与材质。可展示既有角色的坐姿与敲电脑姿态；这是形象要求，不代表动画帧、宠物运行能力或新交互已经开发。前端接入时应保留原宠物开关、尺寸和位置等已有设置行为。

## 7. 图稿与前端验收依据

1. 首页与设置的品牌区、侧栏图标中心、文字起点、菜单高度与圆角一致。
2. 所有图文按钮的图标至文字间距为 8px，不保留 4px、6px、10px 或 16px 的旧间距。
3. 只有两类按钮视觉：白底浅蓝边框，以及实蓝白字；两者共用尺寸与字重基准。
4. 当前导航、当前助手或当前页签具有真实选择态；保存、发送、刷新等动作不产生错误的持续选择态。
5. 输入框仍可输入，按钮仍触发现有动作；控件视觉统一不改变控件语义。
6. 普通默认图标为灰蓝色，蓝色按钮内为白色；品牌 IP 图片保留原色。
7. 侧栏与内容在窄窗口不溢出；任务与最近项目可响应式换列，文字不压到图标上。
8. 桌面宠物、首页主视觉与 logo 使用同一只蓝毛绒水獭，不混入猫或树懒。
9. 正式构建时核对源码与本规范；设计图中的示例数据不能被描述为实际 AI 调用或任务执行结果。
